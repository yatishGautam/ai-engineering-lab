# Paper notes (W20 practice)

One file per paper I read at pass 2 or deeper. Format:

- **Claim** — what they say they achieved
- **Mechanism** — how it works, in my own words + my own diagram
- **Evidence** — baselines fair? ablations present? scale-sensitive? compute-matched?
- **Verdict** — would I use this in my own systems, and with what caveat?

Weekly practice: pass-1 skim 5-10 papers, promote at most one to pass 2.
